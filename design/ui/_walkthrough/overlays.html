分享面板

sheet

遮罩 + 底部圆角弹层 + 拖拽把手。四个渠道（微信 / 朋友圈 / 复制链接 / 生成海报）， 底部分离的「取消」。点遮罩或取消都能关，Esc 也行。

宿主：13-article.html · 导航栏右上角分享图标

二次确认

dialog

居中卡片 + 后果说明 + 左右两个按钮。危险动作在右侧、用红色； 取消在左侧、用中性色。删除 / 清空 / 注销复用同一个组件。

宿主：05-profile.html · 最下方「退出当前账号」

遮罩 Loading

loading

转圈 + 一句「正在生成海报…」。只有转圈没有文案会让人以为卡死， 所以这句说明是必需的。提交表单、AI 生成、支付等待都用它。

宿主：13-article.html · 分享面板里的「生成海报」

断网 + 加载失败

offline / error

顶部暖色断网条（不吓人，带重试）+ 中间错误说明 + 描边重试按钮。 主按钮留给「去别处看看」，重试用描边，避免两个实心按钮抢注意力。

宿主：12-articles.html · 列表加载失败
