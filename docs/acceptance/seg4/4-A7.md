## 4. 工作流点名的三个坑

| 坑 | 怎么排除 |
|---|---|
| 把「装了 `expo-sharing`」当分享可用 | 本段**没有安装 `expo-sharing`**（Web 上无意义）；分享走 `navigator.share`，不存在时置灰并说明——证据是**置灰态 + 文案**，不是「按钮存在」 |
| 下载点的是预览 PNG 而不是 PDF | 落盘文件头断言 `%PDF-`，且字节数 32,430 = 带签 PDF 的大小（预览 PNG 是 377KB） |
| 翻页只验「有第 2 页」没验无交集 | 两页 id 列表逐项求交集，结果为空 |

## 5. 与真机的差异（留段 8）

3. 「打印指定的本地 PDF」（浏览器不允许，本段只验 `window.print()` 被触发）。
4. iOS 端行为差异。
