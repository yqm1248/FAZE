# `4-A5` 签名位置

> 段 4 验收锚点。**容差 ≤ 4mm（≈11.34pt）是技术侧自定、负责人 2026-11-01 授权的**——这是自证，不是第三方验收（工作流 §四 已留痕）。
> 自动化：`deploy/verify-seg4.ps1 -Only 4-A5`（叠章差异包围盒 + 遮挡检查）。

## 1. 结论

**通过**（自动判定 `PASS`）：落点最大偏差 **2.00pt ≈ 0.7mm** ≤ 4mm，且签名落在原本空白的区域（未遮挡正文）。

## 2. 怎么量的（不靠目视）

1. 探针另建一份文书，用**实心矩形**签名图（240×120px 全黑不透明）在**已知坐标**盖章：
   请求 `posX=380 posY=700 width=120 height=60`（屏幕坐标，原点左上；基准页 595×842pt）。
2. `deploy/tools/PdfInspect.java diffbox <带签> <未签>`：两份 PDF 同一页按 **72 DPI 渲染（1px = 1pt）**，逐像素比，
   差异像素的包围盒就是签名墨迹的实际矩形。
3. 量出来的是**墨迹**而非图片矩形，所以预期值也按同一张图的墨迹范围解析算出：
   笔迹像素 `x∈[20,220] y∈[25,95]`（240×120 画布）→ 缩放到 120×60pt 的放置框 →
   预期墨迹矩形 `x=390 y=712.5 w=100 h=35`。
4. 逐边比差值取最大者，与 11.34pt 比。

## 3. 实测

| 项 | 值 |
|---|---|
| 实测墨迹包围盒 | `x=390 y=711 w=102 h=37 pt` |
| 预期墨迹包围盒 | `x=390 y=712.5 w=100 h=35 pt` |
| 各边偏差 | dx=0.00、dy=1.50、dw=2.00、dh=2.00 → **最大 2.00pt（0.71mm）** |
| 是否遮挡正文 | `UNSIGNED-INK-PIXELS 0`——未签 PDF 在该矩形内是**纯白**，说明签名落在空白处 |
| 页数 | 盖前 2 页 / 盖后 2 页（叠章不改页数） |

## 4. 工作流点名的三个坑

| 坑 | 本次怎么排除 |
|---|---|
| 坐标写死、不按 `basePage_*` 缩放 | `SignatureStamper` 用 `scaleX = 实际页宽 / basePageW` 等比换算；单测 `scalesWhenPageSizeDiffers` 用 2 倍页面验过（见 `D2-stamp.md`） |
| Y 轴没换算（PDF 原点在左下） | 若没换算，墨迹会出现在页面底部（y≈82pt 一带）而不是 711pt；单测 `stampLandsAtTopLeftNotBottom` 直接数像素（页顶红、页底白） |
| 截图缩太小看不出偏差 | 不用截图判，用 72 DPI 逐像素包围盒，单位就是 pt |
