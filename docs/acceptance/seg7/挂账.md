## 二、功能/结构缺陷挂账

### 1. 告警通道三条硬缺口（`7-A8` 的核心）

1. **`FazeServiceDown` 永远推不出去**：`AlertDispatcher` 是 `@Scheduled`、跑在 faze-api 进程内，服务一挂派发器自己也不跑。
   修法：派发器挪到独立进程 / 用计划任务跑探活脚本 / 部署 Alertmanager（G2 明确未部署）。
2. **恢复通知在真实 Prometheus 下是死代码**：`/api/v1/alerts` **只返回 pending / firing，不返回 resolved**，`pushResolved()` 拿不到 resolved。改读 `/api/v1/rules` 的 `alerts[].state`（`inactive` 即恢复）并自己维护上次状态。
3. **去重键「先写后发」会吞告警**：`pushFiring()` 先 `SETNX` 再去重键、后发送；发送失败时告警被吞 1 小时。改成先发后写，或发送失败时 `DEL` 键。
4. **真实钉钉群未配**：`sys_config.alert.dingtalk_webhook` 当前是 `http://127.0.0.1:8088/dingtalk`（演练留下的 mock 地址），`alert.dingtalk_secret` 为空串。**换真地址前不要当成「已配置」。**

### 2. 错误码与环境

5. **错误率口径**：`GlobalExceptionHandler` 把所有 `RuntimeException` 映射成 HTTP 200 + 业务码，`status="500"` 恒 0，`FazeHighErrorRate` 在生产**永不 firing**。本批加了 dev-only `/api/v1/dev/fault`（`@Profile("!prod")`）仅供演练。**段 8 要定**：按业务错误码统计错误率，还是保留 5xx 通路。
6. **`management.server.address` 落不了地**：SB4 同端口配该键**启动即失败**（43 个 `@SpringBootTest` 全挂）。现在靠 `SecurityConfig`「本机来源 OR ROLE_ADMIN」+ 只 expose 4 个端点保证不裸奔（实测 `/actuator/env`=404）。**生产部署时必须重评**（给 management 独立端口）。

### 3. 敏感词

7. **`lang` 误配即静默失效**：`SensitiveWordSaveBO.lang` 无白名单，`SensitiveWordEngine.check` 是「请求 lang 的树存在就只查那一棵」。实测用 `lang='zh'` 建的 block 词**永不命中**（保存成功、引擎加载成功、就是不拦）。修法：`lang` 加白名单（`zh-Hans|bo|ug-Arab-CN|kk-Arab-CN`）+ `check` 在精确 lang 未命中时退回全树扫描。
8. **正式词库未就位**：50 条里 `block` 30 条是 `【示例】…` 占位词，三语示意词未做。上线前必须整体替换。

### 4. 导出

9. **异步导出无站内信通知**：`notification.user_id` 指向 `faze_user`，而操作者是 `faze_admin.sys_user` 里的人 → 完成后只落文件 + INFO 日志。段 8 补「管理员 → 站内信」身份映射。
10. **异步导出的 6000 行路径只有单测**：`operation_log` 是只追加表（无 DELETE 权限），造不出可清理的 6000 行。复验办法：把 `FAZE_EXPORT_SYNC_MAX_ROWS` 设成 5，任意导出即转异步。

### 5. 收藏 / 关注

11. **收藏计数与列表可能不一致**（设计如此）：目标下架/归档后列表不展示但计数保留。实测 3 篇文章中 2 篇 `archived` → Tab 显示 3、列表 1 条。**要产品拍板**：要么计数也过滤可见性，要么列表给「已下架」占位。
12. **关注页「在线 + 有新动态」的 article feed 不产出**：`article` 表没有作者字段，无法判断「关注的律师发了文章」。页面已有渲染分支，后端补字段即可用。
13. **收藏/关注未做无限滚动**：有 `cursor` 但只取首屏 + 「没有更多了」。段 8 前补。

### 6. 地区（`region`）

14. **`app_user.region` 无采集点**：V707 建了列与索引、看板/公告链路全通，但**注册流程不采集、资料页也没有该字段** → 恒为 NULL。后果：地区分布只有「其他」一项；**按地区发公告必然 0 人**（正常走完 `sent`，不报错）。需补：注册页或资料页的地区选择器（APP 端）。

### 7. APP 端

15. **`AsyncStorage` 未装**：设置项（字体/深色）Web 走 `localStorage`（重启浏览器保持），**原生退回进程内 Map（真机重启丢设置）**。段 8 装 `@react-native-async-storage/async-storage` 后只改 `features/settings/storage.ts` 一处。
16. **`expo-file-system` 未装**：缓存大小在 Web 是估算（`performance` 资源 + Cache Storage 相加），**原生返回 0，不编数字**。
17. **Ionicons 字形错渲染**：实测某些码位（如 `scale`）在打包字体里渲染成别的字形（CDP 读到 `char=f553` 但屏幕上是「i」）。关于页/我的页 hero 已改用 `react-native-svg` 画天平；**其余装饰图标未逐个排查**。
18. **左滑取消收藏只在 Web 验过**（CDP 真实拖拽）；原生同一 `Swipeable` 实现，段 8 真机补一次。
