──── 二、口径（本段定，后续段不许改）──────────────────────────────────
1. **单日统计口径 = pending + success**（不含 failed / closed）。
   只算 success 的话，用户可以连开多张未支付单占满额度后只付一张，限额形同虚设；
   closed/failed 的钱没进来，占配额就是白占，所以 D2 关单后额度必须自动恢复。
2. **「单日」按东八区自然日**（0 点换日），不是 UTC 0 点。
3. **未实名是拦截不是限额**：unverified_daily_cents <= 0 时直接 405020，
   页面据 realnameRequired 禁用 CTA 并提供实名入口，不显示「今日还可充值 ¥0.00」。
4. 金额与笔数超限**共用一个错误码 405016**（不给攻击者区分维度）。
