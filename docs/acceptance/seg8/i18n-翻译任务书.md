## 三、五条硬规则（违反任何一条，产物直接打回）

1. **key 一个字都不能改**：不改拼写、不增删、不合并、不拆分、不改嵌套层级。`t()` 用 key 查表，改 key = 该条文案永远查不到。
2. **占位符原样保留**：`{{name}}` `{{count}}` `{{date}}` 等共 **89 条 key、106 处**。**占位符名字不能改、不能翻**；它在句子里的**位置可以按目标语言语序移动**。
   - 例：`"今日还剩 {{n}} 次"` → 维吾尔文可以写成 `"بۈگۈن {{n}} قېتىم قالدى"`，但 `{{n}}` 必须原样。
3. **只翻「值」，不翻 key**。JSON 的键名一律保持英文 camelCase。
4. **纯 JSON 输出**：UTF-8 编码、**无 BOM**、2 空格缩进、对象末尾不加逗号、文件末尾一個换行。不要写成 `{"a":1}` 单行（虽然合法，但 diff 不可读）。
5. **不翻这些**：
   - 品牌名「法泽」「FAZE」
   - 法律条文编号里的数字（「第 464 条」的「464」）——中文"条"按目标语言习惯写
   - 金额单位、百分比符号、URL、邮箱、电话
   - `{{...}}` 占位符本身
   - 已经是拉丁字母的专有名词（如 `Android`、`iOS`）

## 四、语言特定要求

### 4.1 维吾尔文 `ug-Arab-CN` / 哈萨克文 `kk-Arab-CN`（阿拉伯字母，RTL）

1. 使用中国境内通用的阿拉伯字母正字法（维吾尔文用 `ئ` 等标准字符，不要用土耳其字母或西里尔字母）。
2. **数字必须用阿拉伯数字 `0-9`（东阿拉伯数字 `٠١٢` 不用）**，且数字、拉丁字母、`{{占位符}}` 在 RTL 文本里保持 LTR 方向——这是渲染层用 `LtrText` 处理的，翻译侧只需**不要在数字两侧加方向控制符**。
3. 标点按目标语言习惯（逗号 `،`、问号 `؟`），不要保留中文全角 `，`。
4. 不要写 `U+2066`~`U+2069` 等 BiDi 控制字符（AGENTS §5 明令禁止）。

### 4.2 藏文 `bo`

1. 标准藏文（卫藏方言书写），词与词之间用 **tsheg `་`（U+0F0B）** 分隔，句末用 **shad `།`（U+0F0D）**。
2. 数字用阿拉伯数字 `0-9`。
3. 不要混入汉字（除「法泽」品牌名本身）。

### 4.3 `error.json` 特殊

它的 key **本身就是完整 msgKey**（如 `error.auth.token-expired`），与其他文件的 `namespace.场景.元素` 结构不同。翻译时：
- key 原样保留（`error.auth.token-expired`）
- 只翻值
- **不要**给 key 加或去掉 `error.` 前缀
