# A-1 隐私弹窗实测截图（2026-11-13 晚）

> **这两张是真渲染的像素，不是设计稿。** 用 CDP `Emulation.setDeviceMetricsOverride`
> 把布局视口设成 **390×844**（`deviceScaleFactor=2`，产物 780×1688）后截的。
>
> 为什么必须这样截：`chrome --headless --screenshot --window-size=390,844` 只改窗口，
> **布局视口实测仍是 ~500px**，卡片按 500 居中后再裁到 390，看起来像"弹窗右侧被切"——
> 那是假象，不是缺陷。第一次就是这么误判的，记在这里免得下一个人重踩。

## 这次的覆盖面与没覆盖的

- 覆盖：首启出现、不同意分支、遮罩不可关闭（点外圈不会消失——DOM 里 mask 无 onPress）、
  文案全部走 `t()`。
- **没覆盖**：点「同意并继续」后的跳转、清 localStorage 后重弹、三种少数民族语言下的
  排版（藏文/维吾尔文/哈萨克文的 RTL 与断行）、真机上的 `Modal` 行为。
  这些属第 8 段工作流 §七 7.1 的验收测试时段，不在本次范围。
