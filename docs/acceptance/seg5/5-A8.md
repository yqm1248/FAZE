# `5-A8` 全局搜索

> 段 5 验收锚点。采集：2026-11-08 16:54，`faze-api` 8081（dev）。
> 证据来源：`PROGRESS-E-H.md` §2.8。

## 1. 结论

**通过**（判据 5/5）：四类结果**分域**返回、各自可跳转、空态与 idle 态齐全。

## 2. 判据

| # | 要求 | 实测 |
|---|---|---|
| 1 | 四类结果**分域展示**（四组，每组有命中数与「查看全部」） | `GET /app/search?kw=合同` → `{lawyers:{list,total}, articles:{list,total}, cases:{list,total}, documents:{list,total}}` **四个域对象** ✅ |
| 2 | 每组都能跳到正确目标页 | 律师→`/lawyer-detail?id=`、文章→`/article?id=`、案例→`/case-detail?id=`、文书→`/doc/form?templateId=` ✅ |
| 3 | 搜不存在的词 → 空态 + 推荐词 | `totalHits=0 → empty` 态，显示「没搜到「kw」相关的内容」+ 4 个推荐 chip ✅ |
| 4 | 未输入时有「搜索历史」与「大家都在搜」 | `idle` 态：历史存本地 `prefStore`（≤10 条、可清空）+ 固定热词 5 个 ✅ |
| 5 | 接口响应是**分域对象**，不是一个大数组 | 见第 1 条；单域 `type=case` 只回 `cases`，其余字段不输出 ✅ |

## 3. 原始响应（`kw=合同`）

```json
{"code":200,"data":{
  "lawyers":{"list":[],"total":0},
  "articles":{"list":[],"total":0},
  "cases":{"list":[],"total":0},
  "documents":{"list":[{"id":"3","name":"劳动合同","category":"劳动文书"},
                       {"id":"4","name":"跨境电商合同","category":"跨境电商"}],"total":2}
}}
```

## 4. 范围约束

- 「文书」域搜的是**模板**（`doc_template`），**不显示价格**（V1 不作文书付费）；
- 不引入 Elasticsearch：四域各一条 `LIKE`，数据量大了再换，不改协议形状；
- 搜索历史**不上服务端**（本地存），热词是前端固定表（V1 没有热门统计接口）。
