## 1. 结论

## 2. 判据

| # | 要求 | 实测 |
|---|---|---|
| 1 | APP 案例列表对应分组（民事纠纷）里可见 | `GET /app/case-library?type=civil` → `[{id:1, title:房屋租赁押金返还争议, caseType:civil}]` ✅ |
| 2 | 详情页四个正文块齐全 | `summary` / `disputeFocus` / `judgment` / `insight` 四块都有值 ✅ |
| 3 | **法条引用正常渲染**成「《中华人民共和国民法典》第七百三十三条」而不是 JSON 原文 | 接口返回结构化 `lawRefs[{lawName, articleNo, lawItemId}]`，App 详情页拼 `《lawName》articleNo` ✅ |
| 4 | 点法条能看到条文原文 | 点条 → `GET /pub/law-items?kw=` → 弹层显示 `content`（第七百三十三条原文）✅ |
| 5 | 大类由细分自动算出（合同纠纷 → civil） | 库里 `category=contract`、`case_type=civil`，**表单只填细分** ✅ |
| 6 | 页面**不显示案号、不显示法院全名** | 详情接口出参**没有** `courtCaseNo` / `courtName` 两个字段 ✅ |
