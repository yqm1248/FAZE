## 4. 修掉的缺陷

`CaseServiceImpl#addProgress` 原实现：

```java
if ("accepted".equals(bo.getNodeCode()) && courtCaseNo 非空) {
    legalCaseMapper.updateCourtCaseNo(...);   // 只写案号
}
```

状态机表里明明有 `ACCEPTED → IN_PROGRESS (LAWYER)`，也有注释「律师登记法院案号」，但代码没接上。实测现象：**案号写进去了、status 还是 accepted**。
修复：accepted 分支里补 `assertCanTransit + casUpdateStatus(accepted → in_progress)`，修复后重测通过。
