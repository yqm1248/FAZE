## 一、可复现的动作序列

### 1.1 关闭开关

```sql
UPDATE sys_config SET config_value='false' WHERE config_key='ai_enabled';
```

### 1.2 后端降级响应（curl，直打接口）

```powershell
curl.exe -s -X POST "http://127.0.0.1:8081/api/v1/app/ai/conversations" `
  -H "Content-Type: application/json; charset=utf-8" -H "X-Device-Id: seg3-lead-verify" `
  -H "Authorization: Bearer <appToken>" --data-binary "@tmp/seg3/inj2.json"
```

实测：

```json
{"code":200,"data":{"conversationId":null,"degraded":true,"messageId":null,"streamUrl":null},"msg":"ok","traceId":"f1f7cda0-b182-4b34-a942-f7f35b366b0c"}
```

判读：`degraded=true`、`conversationId/messageId/streamUrl` 全为 null——**没有建会话、没有发起流式**，是「降级」而不是「错误」（HTTP 200 + code 200）。

### 1.3 前端页面表现（CDP，RN Web）

```powershell
node scripts/cdp-shot.mjs --url "http://127.0.0.1:8090/agent" --out "tmp/seg3/f4-degraded-search.png" `
```

判读：

判读：**能正常搜出结果**（命中 679，走的是 `GET /api/v1/pub/law-items?kw=借条`，B 组接口），不是白屏、不是「暂无数据」。

### 1.5 降级状态下「不调豆包」的证据

判据：服务端日志里降级窗口内**没有任何上游请求**。

```powershell
$log = Get-Content logs/faze-api.out.log -Encoding UTF8 -Tail 600
$log | Select-String -Pattern 'DoubaoClientImpl|WebClient|ark\.cn|Authorization: Bearer'
# → 命中 0 行
```

同时日志里有降级决策的痕迹（`AiProperties` 每次读配置都会打一行）：

```text
2026-11-07 01:59:57 DEBUG [cbb79118-...] c.f.modules.ai.config.AiProperties - AI 配置已加载 enabled=false model=doubao-seed-1.6-32k quota=50 topN=5 ...
2026-11-07 02:00:30 DEBUG [614b0d87-...] c.f.modules.ai.config.AiProperties - AI 配置已加载 enabled=false model=doubao-seed-1.6-32k quota=50 topN=5 ...
```

> **这条判据的强度有限，如实说明**：本环境 `faze.ai.mock=true`，即使 `ai_enabled=true` 也不会真的调上游（走 `DoubaoClientStub`）。所以「日志里没有上游请求」在 mock 下不能完全区分「因为降级没调」和「因为 mock 本来就不调」。**逻辑上的证据是**：C2 的 `AiQuestionService` 在 `ai_enabled=false` 时**在调模型之前就 return**（响应里 `streamUrl=null` 就是证明——没有 streamUrl 就没有流式，也不会有上游调用）。**要彻底证死这一条，需要真实 key 环境复测一次**（`3-A2` 的 key 到手后顺手做）。

### 1.6 重开开关 → 恢复 AI 模式

```sql
UPDATE sys_config SET config_value='true' WHERE config_key='ai_enabled';
```

重载 `/agent` 后实测：

```text
testIds = ["ai-chat-history","ai-chat-clear","ai-quota-text","ai-chat-input","ai-chat-send","tab-home",...]
bodyText = "法泽智能体\n描述你遇到的法律问题，例如「借钱不还怎么办」\n今日还剩 34 次\n发送\n..."
```

判读：`ai-degraded-search` **消失**，`ai-chat-*` 与 `ai-quota-text` **回来**——恢复成 AI 对话页。工作流只要求「重新打开后恢复」，不要求实时热更新，本节是「重进页面」验证，符合。
