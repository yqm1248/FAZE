## 一、逐项判据

### 1.1 按用户 + 时间检索

```powershell
curl.exe -s -H "Authorization: Bearer <adminToken>" `
  "http://127.0.0.1:8081/api/v1/admin/ai-conversations?userId=1&beginTime=2026-11-07&endTime=2026-11-07&pageNum=1&pageSize=3"
```

实测：`total=11`，返回的 `createdAt` 都是 `2026-11-06T17:xx`（UTC）= 北京时间 2026-11-07 01:xx。
**纯日期参数按 Asia/Shanghai 解释**——这一点是验收时发现「UTC 解释会漏掉北京时间当天凌晨的会话」后让后端改的（详见 `H2-a28.md` §八 #2）。

页面侧：查询栏有「用户 ID」输入与「时间范围」下拉（近 7 天），CDP 实测可正常筛选。

### 1.3 只读、无编辑入口

上表三项断言直接对应判据：

- `editInputsInContentArea = 0`：原文/快照区**没有任何输入框**（查询栏的「用户 ID」属于筛选条件，被排除在外）；
- `uniqueButtons = ["若依", "查询", "重置", "导出本条记录"]`：整页只有这三类业务按钮 + 顶部「若依」；
- `hasSaveOrEditOrReviewButton = false`：**不存在**保存/编辑/修改/提交/标记已复核/校验状态这些入口。

工作流 H2 要求删除的两处（「标记已复核」按钮、「校验状态」显示）在页面上确实没有。

## 三、没做到的（如实记录）

1. **导出按钮的真实点击未验**：页面上「导出本条记录」在，但点击后的下载链路（业务 axios 拿不到 `Content-Disposition`、文件名前端拼、截断标记从文件 JSON 读）**没有用鼠标点过**。导出的**接口**已用 `curl` 完整验过（`H2-a28.md` §八 #7：脱敏、`is_exported`、`export_urls`、审计）。这是「按钮→下载」这一段的形式缺口。
2. **200 条截断未验**：开发库没有 200+ 条消息的会话，代码路径在、真实数据证据缺（`H2-a28.md` §八 #8 已如实记「未实测」）。
3. **「用户」筛选只支持 userId**：设计稿写「昵称/手机号/用户 ID」，契约只有 `userId`；运营想按手机号搜得等后端加参数（本段没做，不伪造）。
4. 无真机截图，PC 页面是 1440×900 桌面浏览器截图（A-28 本身就是 PC 后台，不需要手机尺寸）。
