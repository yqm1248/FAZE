> **为什么有这个文件**：`AGENTS.md` §4.12 要求「新增依赖必须先说明理由，并登记到 `docs/architecture/依赖清单.md`」。这份清单只登记**为满足某条验收锚点而新增**的依赖，不重复登记框架自带的东西。

## 一之三、第 0 段 B 组（移动端，2026-11-03）

> 全部用 `npx expo install` 安装，版本由 **SDK 54 兼容矩阵**决定（不手写版本号，避免抄错 `~15.x`）。
> 实测版本（`package.json` 落地值）：`expo-secure-store ~15.0.8` / `expo-constants ~18.0.14` /
> `expo-font ~14.0.12` / `expo-localization ~17.0.9` / `expo-updates ~29.0.20`。

| # | 依赖 | 用在哪 | 为什么必须加 | 不加的代价 | 风险 |
|---|---|---|---|---|---|
| 11 | `expo-secure-store` | B2 会话与设备标识持久化 | token 必须进钥匙串/Keystore；`AsyncStorage` 是明文 | 登录态无处可存，或明文存 token | Android 备份需 `configureAndroidBackup: true`（已在 `app.config.ts` 配）；**Web 上不可用**，本地调试降级 `localStorage`（已在 `tokenStore.ts` 注明，验收记录须记一条） |
| 12 | `expo-constants` | B2 读 `extra.apiBaseUrl` 与 `version` | baseURL 与版本号要在运行时读 manifest | 只能构建期内联 `EXPO_PUBLIC_*`，改地址要重新构建 | 无 |
| 13 | `expo-font` | B3 字体门控（D2 加载藏文/阿拉伯系字体） | 少数民族文字必须自备字体，系统字体不覆盖 | `0-A4` 直接过不了 | 字体商用授权未定（段 0 §十一 #8） |
| 14 | `expo-localization` | B3 首次启动探测系统语言 | 要按系统语言初始化 `faze.lang` | 首次启动只能硬编码中文 | 无 |
| 15 | `expo-updates` | B3 的 `reloadAsync()` 软重启原语 | 切 RTL 后必须重启生效（`forceRTL` 写的是原生标记） | `0-A3` 只能靠手动杀进程验 | **只当软重启原语用**：不配 `updates.url`、`checkAutomatically: NEVER`；`reloadAsync` 在 Expo Go 下不可用（待 D1 实测） |

> **明确不引入**：`axios`（`fetch` 够用，401 并发刷新自己写并不比 interceptor 复杂——判断，非实测）、
> `@react-native-async-storage/async-storage`（token 不许明文存）、`i18next` / `react-i18next`
> （B3 裁决自研，理由见第 0 段工作流 §三 B3 第 1 条）。
> **也不生成 `pnpm-lock.yaml`**：两个 lockfile 共存会让本地与云端装出不同依赖树。

## 二、登记规则

1. **先说明理由再装**。理由要写「解决哪条验收锚点 / 哪个规范条款」，不写「可能有用」。
2. **写清不加的代价**。如果「不加也能凑合」，那就不该加。
3. **写清风险与兜底**。特别是与框架版本冲突时的退路。
4. **禁止**为「让编译通过」而降低 `tsconfig` 的 `strict`、或引入 `@ts-ignore` 类依赖。

## 三、待评估（不装，记录在案）

| 依赖 | 为什么暂不装 |
|---|---|
| `Alertmanager` | 告警通道也是 webhook，但配置与调试成本高；第 7 段用「Prometheus 规则 + 60s 轮询 + 钉钉」实现（G2 已说明是取舍） |
| `node_exporter` | 只提供 CPU/内存/磁盘指标；`7-A8` 用接口错误率就能验，装不装不影响验收（第 7 段标为可选） |
| `logstash` / `ELK` | 需 3 个服务，本机跑不动；JSON 文件 + `Select-String` 已能满足验收 |
| `zipkin` / `otel-collector` | 分布式追踪在单机开发期无价值；`traceId` 已能串链路 |
