## 记录规则

1. **能配置覆盖就不改代码**：优先 `application*.yml`、前端 `.env.*`、路由/菜单配置。
2. 必须改代码时，一次改动一条记录，写清五件事：**改哪个文件 / 为什么必须改 / 影响面 / 回滚方式 / 日期**。
3. 条目 **> 3 条**时停手，按 `pc/README.md` §5 改判为 subtree 或 fork——继续打补丁会让升级不可行。
4. 记录只追加，不改历史条目；回滚后在对应条目补「已回滚 + 日期」。
