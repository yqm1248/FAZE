# 设计令牌说明

令牌的机器可读来源是 [../../design/tokens/tokens.json](../../design/tokens/tokens.json)，
运行时实现是 `apps/mobile-app/shared/theme/tokens.ts`。本文件解释**取值依据**与**变更记录**。

## 1. 为什么配色只取首页

原项目 12 个页面使用了 6 套互不相干的配色体系（去重统计 57 个色值写法）：

| 出处 | 主色 | 问题 |
| --- | --- | --- |
| 登录 / 注册 / 我的 / 起诉状 | `#154A94` 深蓝 | 与首页体系无关联 |
| 律师列表 / 进度 / 筛选 | `#2C9696` 青绿 | 与深蓝并列出现，冷暖冲突 |
| 律师详情 | `#6A82FB → #FC5C7D` 紫粉渐变 | 偏娱乐化，与法律服务调性冲突 |
| 案件中心 | `#A52A2A → #7B1D1D` 红棕 | 三处主色并存 |
| 律师入驻 | `#7289DA` | 接近 Discord 品牌色 |
| 首页 | `#D2E3FB` 渐变 + `#4E6EF2` 蓝 + `#8A2BE2` 紫 | 唯一成体系的一套，冷色淡雅，与法律服务的克制调性一致 |

按"配色以首页为准"的要求，令牌只保留首页体系，其余按
[页面清单与信息架构.md](页面清单与信息架构.md) 第 4 节的映射表替换。

## 2. 单位换算

原项目使用 `rpx`，本项目使用 RN 逻辑像素（dp/pt）。换算基准：

```text
750rpx = 屏宽 = 375dp（iPhone 逻辑宽度）
1rpx = 0.5dp
```

因此原项目的 `24rpx` = `12dp`，`48rpx` = `24dp`。令牌中的 `spacing`/`radius`/`size`
数值已全部换算完毕，**代码中不再出现 rpx 概念**。

## 4. 令牌使用规则

1. 页面与组件**只能**通过 `tokens.*` 取得视觉数值。
2. 需要新的数值时：先判断能否复用既有令牌；确实需要新值时，按"新增令牌流程"操作。
3. 透明度需求不要临时写 `rgba()`。两种做法：
   - 使用 `opacity` 样式属性（适用于整块元素）
   - 在 `tokens.ts` 中定义带 alpha 的专用令牌（适用于单色场景），并在 JSON 中登记

### 新增令牌流程

1. 在 `design/tokens/tokens.json` 增加条目，`note` 必须写明"取自原项目哪个文件"或"为什么需要它"。
2. 在 `apps/mobile-app/shared/theme/tokens.ts` 同步实现。
3. 在本文件第 5 节追加变更记录。
