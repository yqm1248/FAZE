## 全局约定

### 页面四态

每个加载数据的页面都必须处理四种状态，不允许白屏直出：

| 状态 | 表现 |
|---|---|
| 正常 | 数据正常展示 |
| 加载中 | 骨架屏（首次）/ 顶部 Loading（刷新） |
| 空状态 | 空状态插画 + 引导文案 |
| 错误 | 错误提示 + 重试按钮（含断网） |

### 列表页通用能力

所有列表页统一具备：下拉刷新、上拉分页加载、骨架屏、空状态、加载失败重试。

### 返回逻辑

| 场景 | 规则 |
|---|---|
| 系统返回 | 支持侧滑返回 / 物理返回键 |
| 流程完成 | 表单提交成功后，按业务需要 `replace`（不返回表单） |
| 深链接进入 | 返回键逐级回退到上级，无上级回首页 |
| 登录拦截 | 登录成功后返回原目标页（携带 redirect） |

# 全局通用浮层（非独立页面）

| 浮层 | 触发位置 | 内容 |
|---|---|---|
| 隐私政策弹窗 | 首次启动 | 协议摘要 + 同意 / 不同意（不同意退出 App） |
| 语言选择浮层 | 首次启动 / 未选语言 | 4 种语言单选，默认简体中文 |
| 加载 Loading | 提交、生成、支付 | 统一样式，禁止裸奔 |
| Toast 轻提示 | 操作反馈 | 成功 / 失败 / 纯文字，统一时长 |

# 多语言设计说明

## 支持语言

| 语言代码 | 名称 | 书写方向 | 字体方案 |
|---|---|---|---|
| `zh-Hans` | 简体中文 | LTR 从左到右 | 系统默认字体 |
| `bo` | 藏文 | LTR 从左到右 | Noto Sans Tibetan（开源免费） |
| `ug-Arab-CN` | 维吾尔文 | **RTL 从右到左** | Noto Sans Arabic / Noto Naskh Arabic |
| `kk-Arab-CN` | 哈萨克文（中国境内） | **RTL 从右到左** | Noto Sans Arabic / Noto Naskh Arabic |

## 覆盖范围（三层都要做）

| 层级 | 内容 | 实现方式 |
|---|---|---|
| ① UI 界面文案 | 按钮、标题、tabBar、提示语、表单 label | 4 套 i18n 资源，按语言动态加载 |
| ② AI 回答 | AI 按当前 App 语言回答 | 后端 Prompt 注入语言指令，调豆包 API 流式返回 |
| ③ 文章 / 案例内容 | 每日学法、案例详情 | 后台录入 4 语言版本，或机翻辅助 + 人工校对 |

## 关键技术点

1. **RTL 布局**：维文、哈文切换时，整个页面左右镜像（返回箭头在右、文字右对齐、图标翻转）
2. **切换入口**：我的 → 设置 → 语言切换
3. **首次进入**：Splash 后未选语言时弹语言选择浮层
4. **切换生效**：
   - 同方向（中↔藏）即时刷新
   - 跨方向（LTR↔RTL）软重载 1-2 秒（RN I18nManager 限制，下次启动生效）
5. **混排**：法条编号、案号、数字用 LtrText 隔离，不本地化为阿拉伯-印度数字

# AI 接入方案（豆包 API）

| 项 | 方案 |
|---|---|
| 大模型 | 字节跳动豆包大模型 API（后端服务端调用，API Key 不暴露） |
| 模型 | `doubao-seed-1.6` / `doubao-seed-1.6-flash`（**model id 须带完整上下文后缀，以火山控制台为准**） |
| 调用方式 | SSE 流式，前端打字机效果 |
| 系统 Prompt | 「你是**法律信息整理助手**（不是律师），结论 → 法律依据 → 建议路径 → 风险提示，末尾附免责声明」 |
| 多语言 | 后端按当前语言（`zh-Hans`/`bo`/`ug-Arab-CN`/`kk-Arab-CN`）追加语言指令 |
| **法条引用** | **V2.2 变更：建本地法条库**（`law_item` 表，民法典/民诉法等约 2000–3000 条）+ MySQL 全文检索，AI 只能引用检索结果中存在的条文，输出侧做存在性校验 |
| 内容落库 | 每轮对话全量存 `ai_message`，含 `refs` 法条引用快照，供历史回看与追溯 |
| 成本控制 | 每用户每天 50 轮限额，上下文最多 10 轮 |
| ~~不做~~ | **V2.2 变更：向量库仍不做（MySQL 全文索引够用）；但法条库必须建** |
| AI 备案 | **不做**（《暂行办法》第 2 条第 3 款）；上线后如面向公众开放需重新评估 |
