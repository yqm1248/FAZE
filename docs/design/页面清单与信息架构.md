# 页面清单与信息架构

本文档是复刻的**唯一施工图**。任何页面实现必须与本表一致；与原项目不一致的地方，
必须在"偏离登记"小节说明原因。

## 1. 全局结构

```text
启动
 └─ SplashPage  ──有登录态──►  (tabs) HomePage
                        └──无登录态──►  (auth) LoginPage

(tabs) 底部导航 5 项，顺序与原项目一致：
  ┌────────┬────────┬────────┬────────┬────────┐
  │  首页   │  律师   │ 智能体  │  案件   │  我的  │
  │ dibu1  │ dibu2  │  znt   │ dibu3  │ dibu4  │
  └────────┴────────┴────────┴────────┴────────┘

二级页（不出现在 tab，返回上一页）：
  LawyerDetailPage   律师详情      ← 律师列表卡片
  LawyerJoinPage     律师/学生入驻  ← 我的 → 律师/学生入驻
  ProgressPage       查询进程      ← 首页 → 查询进程
  LawsuitFormPage    起诉状生成    ← 首页 → 生成起诉状
```

## 5. 偏离登记

| 页面 | 原实现 | 复刻做法 | 原因 |
| --- | --- | --- | --- |
| AgentChatPage | 有返回按钮（`◁`），但本页在 tabBar 中 | 不显示返回按钮，顶部改为左标题 + 右侧两个图标 | tab 页 `navigateBack` 行为不可预期（在 RN 中会退出应用或无效），属于原设计缺陷 |
| AgentChatPage | 页标题写死「法泽」 | 改为「法泽智能体」 | 与 tab 名「智能体」一致，避免与其他页标题重复 |
| AgentChatPage | 消息列表为空时是纯空白 | 空列表时显示一行引导文案 | 原页面首屏完全空白，用户不知道能输入什么；该文案不改变任何交互 |
| AgentChatPage | AI 回答延迟 1000ms，期间显示全屏 loading | 延迟 600ms，不显示全屏 loading | 全屏 loading 会遮住用户刚发出的消息；缩短延迟以保留「思考」节奏感 |
| HomePage | 右上角「བོད་ཡིག / 中文」语言切换 | 删除 | 本次不做藏文 |
| CaseListPage | 使用 `<div>/<h2>/<main>/<section>` 等 HTML 标签 + `alert()` | 全部改为 `View`/`Text`，`alert` 改 `AppToast` | RN 不支持 HTML 语义标签；原实现只在 H5 端成立 |
| CaseListPage | banner 深红棕底 + 白色标题 | 浅蓝渐变底 + 深色标题 | 底色按配色统一改为首页渐变；白字在浅底上不可读，故标题改为 `text.primary`。属外观改动，依据用户「配色按首页来」的要求 |
| ProfilePage | 头部标语使用楷体 | 只保留字号 24dp、字距 2dp 与加粗 | RN 无法保证楷体在 iOS/Android/Web 三端都存在，指定后会回落到系统默认；保留字号与字距维持原设计的疏朗感 |
| 全部页面 | 图标为 24×24 位图，高分屏发虚 | tab 图标沿用原 PNG（按用户要求）；表单与搜索用矢量图标；个人中心菜单 emoji 保留 | 保留原素材观感，同时避免新增位图。emoji 是原页面的内容元素，替换会改变观感 |
| 全部页面 | 用 rpx 描述尺寸，安全区靠写死 padding | 统一换算为 dp（1rpx = 0.5dp），安全区交给 `useSafeAreaInsets` | 见 [设计令牌.md](设计令牌.md) 第 2 节 |
| 全局 | 无 | 新增 `+not-found.tsx` 404 页 | 原项目未定义，深链失效时用户无处可去 |

## 6. 页面结构速查（复刻时逐项对照）

### HomePage（`pages/index/index.vue`）
1. 顶部渐变 banner：问候语（32rpx/16dp）→ 标语「站在你的角度」（48rpx/24dp 粗体）→ 副标语（28rpx/14dp）
2. AI 解答卡（白底、圆角 12dp、负上边距 -10dp 压在 banner 上）
   - 区块标题「AI 解答」紫色 16dp 粗体
   - 模拟搜索框（灰底、圆角 6dp、高约 22dp）
   - 三宫格功能卡：生成起诉状 / 律师咨询 / 查询进程（描边 1dp、图标 30dp、文字 12dp 粗体）
3. 每日学法卡：标题行（左标题 + 右侧「更多」按钮，带 1dp 描边、圆角 4dp）+ 3 条列表项（标题 14dp、底部 meta 11dp：日期 + 浏览量）

### LawyerListPage（`pages/lawyer/lawyer.vue`）
1. 吸顶搜索栏（白底、圆角 999 灰框、高 38dp）
2. 横滑筛选条：全部 / 民事纠纷 / 刑事辩护 / 婚姻家事 / 合同纠纷（选中态主色填充白字）
3. 律师卡片：竖版头像 65×80（底部叠状态带「在线」）→ 姓名（16dp 粗体）+ 执业年限（11dp 主色）→ 律所（12dp 灰）→ 擅长标签（灰底 11dp）→ 分隔线 → 评分（星标橙）/「已咨询」+ 立即咨询按钮（主色胶囊）
4. 底部文案「已加载全部 N 位专业律师」

### LawyerDetailPage（`pages/lawyer/detail.vue`）
1. 自定义导航（渐变底 + 返回 + 标题）
2. 律师头卡（负上边距压住渐变）：头像 75 圆形 → 姓名 22dp 粗体 + 「资深律师」标签 → 律所·合伙人 → 三栏统计（从业经验 / 好评率 / 咨询次数）
3. 「业务擅长」卡：左侧 5dp 主色竖条 + 标题，标签为圆角胶囊
4. 「个人简介」卡：长段落 15dp / 行高 1.8
5. 底部固定操作栏：全宽主色胶囊按钮「立即咨询」

### AgentChatPage（`pages/ai-agent/ai-agent.vue`）
1. 顶栏：标题 + 右侧两个图标
2. 消息列表：AI 头像 40 圆形在左、白底气泡（右上圆角收窄）；用户头像在右、主色气泡（左上圆角收窄）
3. 底部输入区：白底圆角输入框 + 两个图标按钮，安全区内边距

### CaseListPage（`pages/case/case.vue`）
1. 搜索栏（灰底圆角 10dp）
2. 渐变 banner 高 70dp，居中标题「每日热点案例」+ 下方 30dp 短横线
3. 三个分组：民事纠纷（4 条）/ 行政纠纷（4 条）/ 刑事纠纷（2 条），标题 18dp 粗体，列表项 15dp，底部 1dp 分割线，按下有背景与左移反馈

### ProfilePage（`pages/my/my.vue`）
1. 顶部主色渐变区高 160dp，左侧两行书法体标语「法泽万物 / 法护民生」，右侧半透明天秤 emoji
2. 用户卡（负上边距 -40dp）：圆形头像占位 70 → 用户名 + 脱敏手机号
3. 快捷入口 3 栏（企业认证 / 我的收藏 / 关注律师，竖分割线）
4. 菜单列表 5 项（客服帮助 / 律师与学生入驻 / 常见问题 / 关于投诉 / 设置），emoji 图标 + 右箭头
5. 底部「退出当前账号」描边按钮（红字）

### ProgressPage（`pages/progress/progress.vue`）
1. 吸顶导航（返回 + 标题「查询进程」）
2. 进度卡：案件编号（灰 12dp）+ 状态标签（青绿浅底）→ 案件类型 / 立案日期两行 → 时间轴（2 节点，首节点激活为主色圆点带光晕 + 竖线）

### LawsuitFormPage（`pages/tools/lawsuit-form.vue`）
1. 自定义头部（主色底 + 返回 + 标题）
2. 提示条（浅蓝底 + 主色文字）
3. 四个分组表单：原告信息 / 被告信息 / 诉讼请求 / 事实与理由；每组白底、标题下 1dp 分隔线、输入行底部 1dp 细线
4. 底部主按钮「立即生成起诉状」

### SplashPage（`pages/auth/splash.vue`）
主色渐变全屏 → 居中半透明圆角方框内天秤 emoji → 应用名「法泽」→ 副标语 → 底部旋转 loading + 文案 + 版权

### LoginPage / RegisterPage（`pages/auth/login.vue`、`register.vue`）
左对齐大标题（24dp 主色粗体）+ 副标题（14dp 灰）→ 图标 + 输入行的下划线表单 → 主色胶囊按钮 → 底部切换链接 → 最底部协议文案（11dp 淡灰）
