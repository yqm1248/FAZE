## 5. 偏离登记

| 页面 | 原实现 | 复刻做法 | 原因 |
| --- | --- | --- | --- |
| AgentChatPage | 有返回按钮（`◁`），但本页在 tabBar 中 | 不显示返回按钮，顶部改为左标题 + 右侧两个图标 | tab 页 `navigateBack` 行为不可预期（在 RN 中会退出应用或无效），属于原设计缺陷 |
| AgentChatPage | 页标题写死「法泽」 | 改为「法泽智能体」 | 与 tab 名「智能体」一致，避免与其他页标题重复 |
| AgentChatPage | 消息列表为空时是纯空白 | 空列表时显示一行引导文案 | 原页面首屏完全空白，用户不知道能输入什么；该文案不改变任何交互 |
| AgentChatPage | AI 回答延迟 1000ms，期间显示全屏 loading | 延迟 600ms，不显示全屏 loading | 全屏 loading 会遮住用户刚发出的消息；缩短延迟以保留「思考」节奏感 |
| HomePage | 右上角「བོད་ཡིག / 中文」语言切换 | 删除 | 本次不做藏文 |
| CaseListPage | 使用 `<div>/<h2>/<main>/<section>` 等 HTML 标签 + `alert()` | 全部改为 `View`/`Text`，`alert` 改 `AppToast` | RN 不支持 HTML 语义标签；原实现只在 H5 端成立 |
| CaseListPage | banner 深红棕底 + 白色标题 | 浅蓝渐变底 + 深色标题 | 底色按配色统一改为首页渐变；白字在浅底上不可读，故标题改为 `text.primary`。属外观改动，依据用户「配色按首页来」的要求 |
| ProfilePage | 头部标语使用楷体 | 只保留字号 24dp、字距 2dp 与加粗 | RN 无法保证楷体在 iOS/Android/Web 三端都存在，指定后会回落到系统默认；保留字号与字距维持原设计的疏朗感 |
| 全部页面 | 图标为 24×24 位图，高分屏发虚 | tab 图标沿用原 PNG（按用户要求）；表单与搜索用矢量图标；个人中心菜单 emoji 保留 | 保留原素材观感，同时避免新增位图。emoji 是原页面的内容元素，替换会改变观感 |
| 全部页面 | 用 rpx 描述尺寸，安全区靠写死 padding | 统一换算为 dp（1rpx = 0.5dp），安全区交给 `useSafeAreaInsets` | 见 [设计令牌.md](设计令牌.md) 第 2 节 |
| 全局 | 无 | 新增 `+not-found.tsx` 404 页 | 原项目未定义，深链失效时用户无处可去 |
