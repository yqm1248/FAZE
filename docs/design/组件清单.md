# 组件清单

组件分三层。**新增组件前先查本表**，避免重复实现。

## 1. 共享组件（`shared/components/`）

被两个以上业务域使用的通用组件。

| 组件 | 职责 | 关键 props | 使用方 |
| --- | --- | --- | --- |
| `Screen` | 页面容器：安全区处理、页面底色、可选滚动 | `scroll`、`edges`、`backgroundColor` | 全部页面 |
| `AppHeader` | 自定义导航栏：返回按钮、标题、右侧插槽、可选渐变底 | `title`、`showBack`、`right`、`variant`（`plain` / `brand`） | 二级页、认证页 |
| `AppCard` | 白底卡片：圆角、阴影、内边距 | `padding`、`raised` | 首页、律师、进度、我的 |
| `SectionTitle` | 区块标题：左侧竖条 + 文字，或纯文字 | `text`、`accent`（是否用强调色）、`bar`（是否带竖条） | 首页、律师详情 |
| `PrimaryButton` | 主按钮：实心 / 描边 / 文字三种形态，含按下态 | `label`、`variant`、`disabled`、`onPress` | 全部表单页 |
| `TagChip` | 标签胶囊：灰底、主色浅底、描边三种 | `label`、`variant` | 律师列表、详情 |
| `SearchBar` | 搜索框：只读模拟态与可输入态 | `placeholder`、`editable`、`value`、`onChangeText` | 首页、律师、案件 |
| `AppToast` | 轻提示，替代 `alert()` 与 `uni.showToast` | `show(message, duration)` | 全部页面 |
| `EmptyState` | 空状态占位 | `title`、`description`、`action` | 列表页（暂无数据时） |
| `LoadingOverlay` | 全屏加载遮罩，替代 `uni.showLoading` | `visible`、`text` | 首页跳转、生成起诉状 |

## 2. 业务组件（`features/<domain>/components/`）

| 组件 | 所属域 | 职责 |
| --- | --- | --- |
| `LanguageBadge` | home | 已废弃（不做藏文），不实现 |
| `FunctionGrid` | home | 首页三宫格功能入口（图标 + 文字，带描边） |
| `DailyLawList` | home | 每日学法列表（标题 + 日期 + 浏览量） |
| `LawyerCard` | lawyer | 律师列表卡片（竖版头像 + 状态带 + 信息区 + 咨询按钮） |
| `LawyerFilterBar` | lawyer | 横滑筛选条，受控选中态 |
| `LawyerStatRow` | lawyer | 详情页三栏统计（数值 + 标签） |
| `ChatBubble` | agent | 聊天气泡（AI 左 / 用户右，圆角方向不同） |
| `ChatComposer` | agent | 底部输入区（输入框 + 两个图标按钮） |
| `CaseGroup` | case | 案例分组（组标题 + 条目列表，带按下反馈） |
| `QuickEntryRow` | profile | 三栏快捷入口（带竖分割线） |
| `MenuList` | profile | 菜单列表（emoji 图标 + 文字 + 右箭头） |
| `ProgressTimeline` | progress | 时间轴（节点、状态、时间） |
| `FormField` | tools | 表单行（左标签 + 输入或文本域，底部细线） |
