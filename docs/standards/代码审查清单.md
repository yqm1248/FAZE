# 代码审查清单

合并前逐项确认，任何一项不通过即退回。清单同时用于自检。

## A. 结构

- [ ] 文件位于正确位置（页面在 `features/<domain>/pages/`，路由壳在 `app/`，跨域组件在 `shared/`）
- [ ] `app/` 下的路由文件只有一行 re-export，没有业务逻辑、没有样式、没有状态
- [ ] `features/A` 没有 import `features/B`
- [ ] `shared/` 没有 import `features/`
- [ ] 新增的跨域组件确实被两个以上业务域使用；只有一个域用的组件留在该域 `components/`
- [ ] 没有新增无语义文件名（`utils2.ts`、`newPage.tsx`、`temp.tsx`）

## B. 注释

- [ ] 每个新增/修改文件顶部有块注释，含职责、路由（页面）、数据来源、注意事项
- [ ] 所有导出组件、Hook、函数有注释，含输入输出说明
- [ ] 承担流程步骤的私有函数有注释
- [ ] 单函数超过 3 个逻辑步骤时，步骤之间有阶段注释
- [ ] 非直观样式数值（非常规尺寸、为还原原设计的细节、平台差异）有注释
- [ ] `TODO` / `FIXME` / `TEMP` 带 owner / 范围 / 失效条件
- [ ] 没有被注释掉的死代码

## C. 令牌与视觉

- [ ] 没有任何颜色字面量（`#RRGGBB`、`rgba(...)`）出现在 `features/` 或 `app/` 中
- [ ] 字号、间距、圆角来自 `tokens.fontSize` / `tokens.spacing` / `tokens.radius`
- [ ] 若新增了令牌，已同步 `design/tokens/tokens.json`、`shared/theme/tokens.ts`、
      `docs/design/设计令牌.md` 三处，并写明取值来源
- [ ] 页面视觉与原项目对应文件目视一致（或在 `docs/design/页面清单与信息架构.md` 登记了有意的偏离及原因）

## D. 类型与状态

- [ ] 没有 `any`、没有 `@ts-ignore`、没有 `as unknown as`
- [ ] 假数据有显式类型，且已抽到 `__fixtures__/`
- [ ] 页面内没有超过 5 行的内联数组/对象常量
- [ ] `tsconfig` 的 `strict` 未被放宽

## E. 交互

- [ ] 每个可点击元素都有可见的反馈（按下态、水波纹或状态变化）
- [ ] 跳转使用 `shared/navigation` 的路由常量，没有散落的路径字符串
- [ ] 需要返回的页面有返回入口；tab 页没有多余返回按钮
- [ ] 空状态、超长文本、小屏（360dp 宽）三种情况已目视检查
- [ ] 没有 `alert()`；提示统一走 `AppToast` 或 `Alert.alert`

## F. 构建与运行

- [ ] `npm run lint` 通过（`tsc --noEmit` + `eslint` 零告警）
- [ ] `npm run web` 能启动，改动页面可正常访问
- [ ] 无新增未使用依赖；新增依赖已在 `docs/architecture/依赖清单.md` 登记理由
- [ ] 提交信息符合 `AGENTS.md` 第 6 节「提交规则」的格式（类型 6 种 + 范围枚举）
- [ ] 未提交 `node_modules/`、`.expo/`、构建产物、日志

## G. 文档

- [ ] `docs/design/页面清单与信息架构.md` 的完成状态已更新
- [ ] 若新增页面，页面清单、组件清单、路由表三处已同步
- [ ] 若有与原项目不一致的决策，已在该页面的说明中登记"偏离原因"
