# 字体选型（少数民族文字）

> **为什么有这份文件**：总纲 §5.1 的「出口三件」之一要求把**字体选型结论**写进 `docs/standards/`。
> 段 0 的 `0-A4`（藏文渲染）与整站 RTL 都依赖它。

---

## 一、结论

| 语言 | 字体 | 文件 | 大小 | 许可 |
|---|---|---|---|---|
| 藏文 `bo` | **Noto Serif Tibetan** | `assets/fonts/NotoSerifTibetan-Variable.ttf` | 2,063,504 B | SIL Open Font License 1.1 |
| 维吾尔文 `ug-Arab-CN` / 哈萨克文 `kk-Arab-CN` | **Noto Naskh Arabic** | `assets/fonts/NotoNaskhArabic-Variable.ttf` | 307,592 B | SIL Open Font License 1.1 |
| 简体中文 `zh-Hans` | 系统字体 | — | — | — |

两份许可原文随字体一起入库：`assets/fonts/OFL-NotoSerifTibetan.txt`、`OFL-NotoNaskhArabic.txt`。

## 二、为什么藏文用 Serif，而不是用户指定的 Noto Sans Tibetan

用户 2026-11-04 指定 **Noto Sans Tibetan**（SIL OFL 1.1，`notofonts/notofonts.github.io`）。实测：

| 尝试 | 结果 |
|---|---|
| `google/fonts` 的 `ofl/notosanstibetan/` 目录 | **404**（该目录不存在） |
| `google/fonts` 的 `ofl/notoseriftibetan/` | ✅ 存在（`NotoSerifTibetan[wght].ttf`） |
| `notofonts/notofonts.github.io` 的 `fonts/NotoSansTibetan/{hinted,unhinted,full}/ttf/...` | **全部 404** |
| `notofonts/tibetan` 仓库 | 404 |

**结论**：Google Fonts 上收录的藏文 Noto 只有 **Serif** 版；Sans 版在可达来源里找不到。

采用 Noto Serif Tibetan 的理由：① 同为 **SIL OFL 1.1**，商用/再分发条件一致；② 藏文字形覆盖完整；
③ 是 Google Fonts 的官方收录版本，长期可得。差别只在serif/sans 风格，不影响 `0-A4` 的判据
（判据是「无豆腐块、无断笔、叠字正确」，不是「必须是 sans」）。

**换回 Sans 的成本**：只改两处——`shared/theme/fonts.ts` 的 `FONT_ASSETS`（文件映射）与
`FONT_FAMILY.tibetan`（族名，必须与 `useFonts` 的 key 一致）。拿到 Sans 文件后十分钟内可换。

## 三、SIL OFL 1.1 的义务（必须遵守）

| 义务 | 本仓库怎么满足 |
|---|---|
| 随分发保留版权声明与许可文本 | 两份 `OFL-*.txt` 与字体一起入库，**不许删** |
| 不得单独售卖字体文件本身 | 字体随 App 分发，不单独售卖 |
| 修改版不得使用原保留字体名（Reserved Font Name） | **不修改字体文件**（直接使用官方 ttf） |
| 衍生作品须同样以 OFL 分发 | 本仓库未做衍生 |

## 四、加载与使用

- **加载**：`app/_layout.tsx` 的 `useFonts(FONT_ASSETS)`。字体未就绪时**只铺底色、不渲染路由树**（避免先闪系统字形再跳自定义字形）；**加载失败则回退系统字体继续渲染**（不卡启动屏）。
- **使用**：`shared/components/LocalizedText.tsx` 按 Unicode 区段切 run——
  藏文用 `FONT_FAMILY.tibetan`，阿拉伯系用 `FONT_FAMILY.arabic`，其余走系统字体。
- **字形一致性**：字体族名与 `useFonts` 的 key 不一致 = 加载了但引不到，表现是「仍是系统字形」。改了任一处必须同步另一处。

## 五、为什么是可变字体（`[wght]`）

Google Fonts 仓库只提供可变字体。`expo-font` 按默认实例加载，段 0 只用 Regular 字形、不切字重，
因此没有影响。若将来要按 weight 切换，需换成静态实例（`static/` 目录）。

## 六、仍未验证的项（进第四节挂账）

| 项 | 为什么未验 | 什么时候验 |
|---|---|---|
