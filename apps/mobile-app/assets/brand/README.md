## 3. 为什么前景图**不是透明底**（重要，别照着商店推荐值以为这里错了）

Android 自适应图标的推荐做法是「**透明前景 + `backgroundColor` 纯色**」。本仓做不到，因为源图是**不透明白底的位图**，没有分层。

抠图不是不能做，是**会改画风**：这个 logo 有两个青色调（暗 `#108090` 一档、亮 `#30B0B0` 一档），单一 alpha 反解会把亮色调判成半透明、暗色调边缘发黑。与其交付一个"看起来能用但边缘毛刺"的前景，不如**用不透明白底**——厂商蒙版裁出来就是白底 + 居中字形，视觉上完全成立，且零风险。

所以 `adaptiveIcon.backgroundColor` 填 `#FFFFFF`（与前景图白底一致），不是 `#F7F8FA`（设计稿页底色）。两者在缩放时露出的色差会显脏。

**要真正的透明前景，需要设计出透明源文件**（AI/PSD 分层稿导出 1024 透明 PNG），那一步不是技术侧能补的。

## 4. 已知限制

- 启动页 `splash` 用的是这张**白底方图**，而 `splash.backgroundColor` 是 `#F7F8FA`。两者差 5/255（约 2%），正常屏幕上看不出来，但**深色模式或高对比度屏上可能看到一块方形浅边**。要做成无边的启动图，同样需要透明源文件。
- `assets/legacy/logo.png`（uni-app 默认模板图标）**仍然保留**：`assets/legacy/index.ts` 里还导出了 `appLogo`（当前无页面使用）。删不删等确认没有历史引用再说，别顺手删。
- Web `favicon` 用的是 1024 方图，浏览器会自己缩。要更清晰可以另外出一个 32×32/48×48 的，本段没做。
