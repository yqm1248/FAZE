# apps/ —— 应用端目录

本目录只承载直接面向用户的客户端应用。

| 目录 | 职责 | 技术栈 | 验证入口 |
| --- | --- | --- | --- |
| `mobile-app/` | 法泽 APP，12 个页面的 UI 复刻 | Expo SDK 54 / React Native 0.81 / TypeScript | `cd mobile-app && npm run lint`、`npm run web` |

## 边界

- 当前只有一个应用端。将来若新增（例如 PC 管理端），每个端占一个子目录，
  并在此表登记端类型、技术栈与验证入口。
- 不允许把某端的页面、组件或 API 封装复制到另一端后再改。跨端共享业务能力应通过接口契约，
  共享 UI 组件应沉淀到各自的 `shared/`，而不是互相引用。
- 每个端目录必须有独立 `README.md`，第一段写明"这是哪个端，不是哪个端"。
