# scripts/ —— 脚本入口

本目录是仓库级脚本的唯一入口。**当前为空**，因为所有验证都能通过 `apps/mobile-app/package.json`
的 npm scripts 直接完成，不需要额外包装。

## 约定

新增脚本前先判断：

| 需求 | 处理方式 |
| --- | --- |
| 单个应用的构建、检查、启动 | 放在该应用自己的 `package.json` scripts 里，**不要**进本目录 |
| 跨应用的操作（多端联调、统一检查） | 放本目录，且命名为 `<动作>-<对象>.ps1` |
| 一次性数据处理 | 放本目录的 `tools/` 子目录，并在文件头注释写清用途与可重复执行性 |

## 脚本文件头必须说明

```powershell
<#
.SYNOPSIS
  一句话说明这个脚本做什么。
.DESCRIPTION
  影响范围：会读写哪些目录或数据库。
  是否可重复执行：是 / 否。
  是否有副作用：删除文件、修改配置、启动进程等。
#>
```

## 将来可能需要补的脚本

- `check-all.ps1`：一次跑完 `apps/*` 的 lint 与 typecheck。
- `dev.ps1`：同时启动多端（目前只有一端，暂不需要）。
